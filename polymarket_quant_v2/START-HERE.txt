POLYMARKET QUANT BRIDGE V3
==========================================================

Run the numbered files in order. Nothing else is needed.


BEFORE YOU START
----------------------------------------------------------
Extract this folder so that it sits NEXT TO your data folder:

    ...\polymarket_quant_v2\        <- this folder
    ...\Polymarket-Bot-DATA\        <- your existing data

If they are not side by side, step 1 will stop and tell you
exactly what to set.

You need Python 3.11 or newer, with "Add python.exe to PATH"
ticked during its setup. Nothing else installs - this system
uses only the Python standard library.


THE STEPS
----------------------------------------------------------

  1-INSTALL.bat        ~15 min   Run once.
                                 Checks everything, runs the
                                 test suite, proves the capital
                                 model at your bankroll, runs
                                 the first research pass, then
                                 shows results and opens the
                                 dashboard.

  2-COLLECT.bat        ~20 min   Run after step 1, then whenever
                                 you want fresh data.
                                 Captures live data, repairs what
                                 it can, re-runs the research ONLY
                                 if the data actually improved,
                                 then shows results.
                                 Takes ~6 min when nothing changed.

  3-RESULTS.bat        ~4 min    Optional. Steps 1 and 2 run this
                                 for you at the end.
                                 Double-click it any time to
                                 re-read the findings without
                                 re-running the research.

  4-DASHBOARD.vbs      instant   Reopens the dashboard at
                                 http://127.0.0.1:8787/

  5-STOP-DASHBOARD.bat instant   Stops the background dashboard.

  6-ASK-THE-AI.bat     instant   Talk to the intelligence built into
                                 this system. Same thing as the
                                 dashboard's CHAT page, in a window.


ASKING IT THINGS
----------------------------------------------------------
The dashboard's first page is CHAT. Type an ordinary
question or an instruction - no commands, no syntax:

    Audit the entire system
    Why is the news panel empty?
    What should I do next?
    Analyse every wallet

Each answer shows the figures it read, where it read them,
and what it cannot do about the request. It does not need
an internet connection or an AI subscription: the answers
are computed from your own data. If you connect a local
model later it will add a plain-English summary on top -
it will never supply a number.

It also reads documents. Drag a research note's path into
the box - or run "pqv3 ingest thatfile.docx" - and it will
pull out the claims and turn them into things it can
actually test. Word, Excel, CSV, JSON and plain text all
work. PDF does not, and it will say so rather than guess.
Nothing a document claims is believed: each claim becomes
a candidate that has to survive the same testing as
everything else.

And it tells you what it noticed on its own - a collector
that stopped, a loss run getting close to the stop limit -
at the top of your next answer. Only things worth the
interruption; the rest is filed under ACTIVITY.

IT CAN ALSO CHANGE THE PROGRAM FOR YOU
----------------------------------------------------------
Everything above works with no internet and no AI account.
If you connect a local model, the console gains the ability
to do engineering work on this system - not describe it, do
it:

    the news collector is broken, find out why and fix it
    add average hold time to the wallets page
    find your weakest research step and improve it

It opens the files, makes the change, runs the test suite,
fixes its own mistakes, then tells you exactly what it
changed and the one command that undoes all of it.

To switch it on: install Ollama (ollama.com), run
"ollama pull qwen2.5-coder:14b", then open 6-ASK-THE-AI.bat
in Notepad and un-comment the four lines under MODEL SETUP.
Any OpenAI-compatible endpoint works, local or remote.

Whatever you ask it, it cannot place an order and cannot
turn on live trading. Those stay separate, deliberate human
actions.


YOUR STARTING BANKROLL
----------------------------------------------------------
$100 is only a default. It is never assumed anywhere in the
code. To change it, edit ONE line near the top of
1-INSTALL.bat:

    set "PQV3_STARTING_CAPITAL=100"

Every risk limit is a percentage of equity, so the model
behaves the same at any size. What does NOT scale is the
exchange's minimum order - which is why you will see some
trades refused as CAPITAL_INFEASIBLE at small balances.
That refusal is correct, not a bug.


THREE THINGS THAT LOOK LIKE FAULTS BUT ARE NOT
----------------------------------------------------------

1. Step 2 says "NO MATCHES" on the settlement repair.

   Expected. Those markets are not in the venue's public
   catalogue, so their exact resolution times cannot be
   recovered. Re-running will not change it. Markets that
   resolve while collection is RUNNING do get accurate
   timestamps - so the fix is to leave it running, not to
   repeat the step.

2. News, Blockchain and Microstructure panels are empty.

   Expected on a fresh install. That data has no history in
   this project and cannot be backfilled - it accumulates
   from the moment you start collecting. The panels say so
   rather than showing zeros.

3. Every market says DO NOT TRADE.

   Read 3-RESULTS.bat step [2/4]. It names the exact gate
   and the exact number. On the supplied data the honest
   answer is that the measured edge is smaller than the
   trading costs at the moment the signal fires - so
   refusing is correct.


LIVE TRADING
----------------------------------------------------------
It is OFF, and no step above can turn it on. Enabling it is
a separate, deliberate act that records what was and was not
verified at the moment you approved it.


IF SOMETHING GOES WRONG
----------------------------------------------------------
Send back whichever log matches the step that failed:

    var\install-run.log
    var\collect-run.log
    var\results.log

Each one contains the complete output of that step.
